1. To check status:
   kubectl get pods,svc -l app={{ include "movie.name" . }} -n {{ .Release.Namespace }}

2. Frontend service:
   kubectl get svc {{ printf "%s-frontend" .Release.Name }} -n {{ .Release.Namespace }}

3. Port-forward frontend to test locally:
   kubectl port-forward svc/{{ printf "%s-frontend" .Release.Name }} 3000:{{ .Values.service.frontend.port }} -n {{ .Release.Namespace }}
   Open http://localhost:3000

4. Backend service (internal):
   kubectl get svc {{ printf "%s-backend" .Release.Name }} -n {{ .Release.Namespace }}

5. Upgrade image quickly:
   helm upgrade {{ .Release.Name }} . --set image.frontend.tag=NEWTAG --set image.backend.tag=NEWTAG -n {{ .Release.Namespace }}
